把人生分成一段一段，认真走过，慢慢变好

版本 1.0 需要 iOS 16.0 或更高版本 完全离线 · 本地存储

应用简介

「拾段」是一款以「人生阶段」为单位的记录工具。无论是求职、备考冲刺、休养调整、走出失恋，还是任何一段想认真对待的日子，你都可以为它开启一个阶段，每天用心情、标签、文字和照片留下痕迹；阶段结束时封存它，并收到一封属于自己的终章寄语。 所有数据仅保存在你的设备本地，无需注册账号、无需联网，安静且私密。

核心功能

段

人生阶段

内置求职、备考冲刺、休养调整、走出失恋模板，也可完全自定义阶段。

记

每日记录

5 种心情、场景化标签与自定义标签、文字和照片，配合每日一句记录当天状态。

墙

照片墙背景

记录中的照片自动在首页卡片与阶段详情拼合成照片墙背景（VIP 功能）。

板

数据回顾

心情分布、高频标签等统计图表（App 内入口为「回顾」），直观看见变化轨迹。

章

封存与寄语

阶段结束可选择原因封存，封存后只读留存，并查看专属终章寄语。

锁

隐私锁

支持 Face ID / Touch ID 解锁，生物校验仅在本机完成，保护私人记录。

快速上手

  1. 首页点击「＋」，选择一个模板或自定义，开启你的第一个人生阶段。
  2. 进入阶段详情，点击「记录」，选择今日心情、标签，可补充文字与照片后保存。
  3. 坚持每日记录，累计 7 / 30 / 180 / 365 天会解锁里程碑彩蛋。
  4. 点击底部「回顾」查看心情分布与高频标签等统计（VIP 功能）。
  5. 阶段结束时，于详情页右上角「更多」中选择「封存此阶段」并填写原因。
  6. 左滑某一天的记录可删除（会二次确认）；可在「设置」中开启 Face ID / Touch ID 隐私锁。

常见问题 FAQ

数据保存在哪里？使用需要联网吗？
「拾段」不连接任何服务器、不需要注册账号，也不联网。你的周期、记录、文字和照片全部只保存在当前设备本地，离线也能正常使用。正因如此，卸载应用会清除全部数据，且不会自动云端同步，更换设备前请自行截图留存。
免费版和 VIP 有什么区别？会自动续费吗？
免费版仅可开启 1 个人生阶段，且不包含数据回顾（看板）与照片墙背景，记录页的照片入口会显示为「VIP 功能，解锁后可用」。VIP 为一次性购买、永久解锁的非消耗型项目（一次购买解锁全部功能）：可开启不限数量的人生阶段，并使用完整数据回顾与照片墙背景。没有订阅、没有到期时间、不会自动续费。
换了手机或重装应用，数据还在吗？
数据仅存储于本机，不会自动同步到新设备。删除应用或恢复出厂设置后，本地记录将被清除且无法找回，请提前自行备份重要内容（如截图或保存终章卡片到相册）。
换设备 / 重装后如何恢复已购买的 VIP？
进入「设置 → VIP 会员 → 恢复购买」，使用当初购买时的同一个 Apple ID 登录即可恢复，无需再次付费。VIP 为非消耗型商品，一次购买终身有效。
误删了周期或某条记录，能找回吗？
删除前会弹出二次确认。由于数据仅保存在本地且没有云端备份，确认删除后无法恢复，请谨慎操作。
如何开启 Face ID / Touch ID 锁屏？
在「设置」中打开面容 / 触控锁定开关即可。解锁校验由 iOS 系统在本机完成，应用不会获取、保存或上传你的生物特征信息。
给记录选照片时，为什么不需要授权访问整个相册？
应用使用 iOS 的系统照片选择器（PHPicker），你只能、应用也只会读取你主动选中的图片，应用不会扫描或遍历你的整个相册；这些照片仅保存在本机，用于记录配图并拼合照片墙背景（照片墙为 VIP 功能）。把终章卡片保存到相册时，系统会就「写入相册」单独征求你的同意。
封存周期后还能继续编辑吗？
封存代表这一阶段已经结束，封存后的阶段将变为只读，不能再新增、修改或左滑删除记录，但可以随时回看，并查看为这段旅程生成的终章寄语。
如何删除某一天的记录或管理自定义标签？
在阶段详情页向左滑动某条记录，点击出现的删除按钮并确认即可（已封存的阶段为只读，不支持滑动删除）。在新增 / 编辑记录页的标签区，长按自定义标签可将其删除（仅作用于当前阶段所属主题，删除前会二次确认）。
照片墙背景是怎么生成和排序的？
照片墙是 VIP 功能：你在记录中添加的照片仅在本机自动拼合为首页卡片与阶段详情的背景，最新照片显示在最前；每层最多 6 张、最多 6 层，照片较多时各层尽量均分，超出 36 张后只保留最新的 36 张。照片不会上传，删除记录或关闭相应功能后背景即不再显示。
内购被误扣费，如何申请退款？
应用内购买由 Apple App Store 统一处理，开发者无法直接操作退款。请使用购买时的 Apple ID 访问 reportaproblem.apple.com，按提示向 Apple 申请退款或查看订单。
支持哪些设备和系统？
支持运行 iOS 16.0 及以上系统的 iPhone，针对竖屏使用做了适配。
